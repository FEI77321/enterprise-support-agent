# IT 资产生命周期标准操作流程

## 适用范围

本流程适用于公司采购、领用、调拨、维修和报废的笔记本、显示器、移动设备及其配件。每项资产必须使用资产标签作为唯一追踪标识。

## 新设备领用

1. 员工在服务台提交设备申请，并写明岗位、成本中心和交付日期。
2. 直属主管确认业务必要性；金额超过 8000 元时，部门负责人还需审批。
3. IT 资产管理员登记序列号、资产标签和领用人，并在交付单上保留签收记录。

## 调拨与离职回收

设备调拨前必须完成数据备份和设备检查。员工离职前 3 个工作日，HR 会向 IT 发送回收清单；IT 必须在最后工作日当天将资产状态更新为“已回收”。

## 例外处理

损坏设备不得直接报废。IT 应先创建维修记录；无法维修且预计维修成本超过重置成本 60% 时，才能提交报废申请。
