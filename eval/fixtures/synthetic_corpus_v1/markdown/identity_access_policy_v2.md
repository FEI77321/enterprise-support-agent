# 身份与访问权限管理制度 v2.0

> 文档版本：v2.0；生效日期：2026-10-01；替代：`identity_access_policy_v1.md`。

## 新员工开户

HR 在员工入职前 3 个工作日提交开户申请。IT 按岗位模板创建企业账号、邮箱和基础协作工具权限；管理员权限不得随开户流程自动授予。

## 权限申请

系统权限必须遵循最小权限原则。普通业务系统由直属主管审批；财务系统额外需要财务负责人审批。生产环境只读权限还需要系统负责人审批，写权限必须同时获得系统负责人和信息安全负责人审批。

## 离职停用

HR 确认离职后，IT 应在最后工作日 17:00 前停用账号。高权限账号需要在停用后保留 180 天审计记录，并在 24 小时内完成令牌和 API Key 的轮换检查。
